BigBuncher UI Assets
====================

Style: dark minimalist Minecraft launcher, charcoal panels, green accents, voxel landscapes.

Folders:
- 01_launcher: main launcher screen concept.
- 02_backgrounds: landscape and branded background crops.
- 03_controls: buttons, toggles, chips and navigation control references.
- 04_icons: icon collection reference.
- 05_panels: settings, news, install and version-selection panel references.
- 06_decor: decorative shapes, card backgrounds and brand elements.

Important:
These files are visual concept assets cropped from one generated UI board. Some crops contain multiple elements together rather than separate transparent button/icon files. Text and fine details in the board are concept-level and may need to be recreated cleanly in the final app UI.
